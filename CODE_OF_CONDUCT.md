# Code of Conduct

This project follows the Contributor Covenant version 2.1.
The full text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

## Expected behavior

Be kind and respectful.
Accept criticism that helps the work.
Focus on what is best for the community.

## Unacceptable behavior

Do not insult or harass people.
Do not publish private information without permission.
Do not use sexual language or sexual images.
Do not attack a person in public or in private.

## Enforcement

Maintainers enforce this code.
Maintainers can remove comments, commits, or people who break this code.
Maintainers who do not follow this code can lose their role.

## Report a problem

Open a GitHub issue titled `Conduct report` without details, and the maintainers will reply with a private channel.
Do not put private details in the issue.
