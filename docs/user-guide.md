# User guide

1. Open the app, complete **Setup** with a passkey.
2. Create decks on **Decks**, add notes, study on **Study**.
3. Use **Browse** to search cards; **Stats** for retention and forecast.
4. **Settings → Data** for import, export, and trash.
5. **Settings → Pair app** to connect an iOS companion (QR / pairing code). See [ios-pairing.md](./ios-pairing.md).
6. Command palette: open with the keybind shown in the status line.

Keyboard study ratings match the on-screen labels (Again / Hard / Good / Easy).
